## How to add a new paper

1. Add the PDF to the repo root (or an `assets/papers/` folder if you prefer).
2. Create a new file in `_papers/` (example: `_papers/2026-02-10-my-paper.md`).
3. Fill in:

- `title`, `authors`, `venue`, `year`
- `pdf` (local path like `/main-4.pdf`)
- `tldr`, `highlights`, `contributions`
- optional: `code`, `slides`, `abstract`

4. Commit and push.
